# Udemy Clone (HTML + CSS)


A **static UI clone** of the Udemy learning platform built using **HTML and CSS**.
This project focuses on recreating Udemy’s clean layout and design with responsive styling.


## 🚀 Features
- **Homepage Layout**: Search bar, navigation menu, categories (Development, Business, IT, Design, etc.)
- **Flash Sale Banner**: Promotional section with highlight offers.
- **Course Cards**: Display of courses with title, instructor, rating, and price.
- **Topics Section**: Recommended topics like JavaScript, React, AWS, Docker, GitHub, and more.
- **Footer Section**: Includes links to Udemy Business, Teach on Udemy, About, Careers, Blog, Help, and more.


## 🛠️ Tech Stack
- **HTML5** for structure
- **CSS3** for styling and responsiveness


## 🎯 Purpose
This project was built to practice **frontend development fundamentals** using only HTML and CSS.
It replicates Udemy’s design for learning purposes only and does not include backend functionality.
